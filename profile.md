# What reaches my phone

Edit this file to tune the AI triage. It is read on every run and added to the
AI's instructions. The repo is public, so to keep it private put the same text
in a `PROFILE` GitHub secret instead (the secret wins over this file).

## Send immediately (urgent)
- Free API credits, free API tiers or free API keys for strong models that I can call from code
  (OpenAI-compatible endpoint, SDK, or a coding agent like Claude Code, Cline, Aider, Cursor).
- Priority providers: Anthropic / Claude, OpenRouter, Groq, Google Gemini, OpenAI, DeepSeek, Mistral, Cerebras, Together AI.
- Any qualifying offer with a promo code, or one that expires within 72 hours.
- Free plans or credits for AI coding agents and IDEs.

## Daily digest (worth a look, not urgent)
- Cloud and startup credit programs (AWS Activate, Google for Startups, Microsoft Founders Hub) that include AI model usage.
- New free models on gateways, raised free-tier limits, hackathon or student credits that I could realistically get.

## Never send
- Discussion posts, opinions, show-and-tell projects, tutorials, guides, questions, complaints and memes.
- News about funding, revenue, benchmarks, model launches or company spending with no free offer I can claim.
- Paid plans without a free trial, consumer chat app subscriptions (Claude Pro, ChatGPT Plus) and browser-only chat wrappers.
- Expired offers, waitlists, rumours, referral spam and anything that needs a credit card for something I would be billed for.
